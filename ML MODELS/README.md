# 📈 Salary Predictor Desktop Application

A lightweight, standalone desktop GUI application that predicts employee salary based on years of experience using Simple Linear Regression (Ordinary Least Squares).

---

## ✨ Features

* **Interactive Multi-Page UI:** Clean modern layout built using CustomTkinter.
* **Live Mathematical Plots:** Embedded graphical representation using Matplotlib.
* **Terminal Logging:** Real-time color-coded console logs via Colorama.
* **Zero-Dependency Executable:** Fully compiled using PyInstaller—runs on Windows without requiring Python.

---

## 🚀 Quick Start (Executable)

No Python installation or environment setup required.

1. Go to the repository Releases page.
2. Download `mmm.zip` under the **Assets** section.
3. Extract the downloaded ZIP folder.
4. Double-click `mmm.exe` to run the application.

> **Note:** If Windows SmartScreen appears, click **More info** -> **Run anyway**.

---

## 🛠️ Run from Source Code

If you prefer running the code directly:

1. Install dependencies: `pip install -r requirements.txt`
2. Launch application: `python main.py`

---

## 🧰 Tech Stack

* **Language:** Python
* **GUI Framework:** CustomTkinter
* **Data & Visualization:** Matplotlib, NumPy
* **Terminal Output:** Colorama
* **Compilation:** PyInstaller
